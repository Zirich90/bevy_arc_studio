# 06. Каркас тактической RPG поверх BevyArcStudioPlugin

Принцип каждого модуля: чистая логика с юнит-тестами → тонкий ECS-слой → `StudioCommand` → скриншот через BRP.

## Масштаб единиц: футы ↔ мир
Правила PF2e считаются в футах, мир измеряется в метрах. Связь задаёт один коэффициент `UnitScale.world_per_foot` (`arc_core::UnitScale`):

| Режим | `world_per_foot` | Смысл |
|---|---|---|
| `UnitScale::REAL` | 0.3048 | точный пересчёт: 5 фт = 1.524 м |
| `UnitScale::GAME` (по умолчанию для RPG) | 1.0 | игровой: 5 фт = 5 м, 1 клетка PF2e = 5 м |

Вся логика правил хранит расстояния в футах, а ECS-слой переводит их через `UnitScale`. Переключение режима не меняет правила, только геометрию мира.

## Принцип свободного движения (BG3 / WotR)
- Позиция актора непрерывная, сетки нет. Расстояние — евклидова длина пути.
- Стоимость пути: ∫ cost(terrain(x)) ds. Сложная местность (слои splatmap, вода) стоит ×2.
- Бюджет хода: Speed за действие Stride, остаток тратится непрерывно.

## Шаг 0 (этап 06). Reflect-сцена
`DynamicWorld` (`bevy::world_serialization`, в 0.20 бывший `DynamicScene`) + реестр сохраняемых компонентов `SceneComponentRegistry`. Любой `#[derive(Reflect)]` компонент, зарегистрированный в реестре, попадает в сохранение, инспектор и BRP автоматически.

## Модуль 1. `arc_movement`: коллизии, навигация, контроллер
- Билинейная высота земли, растр проходимости 0.5 м (ускоритель запросов, не сетка движения), эрозия препятствий на радиус агента.
- Theta* (any-angle) + funnel-сглаживание, ORCA для локального избегания, инвалидация dirty-rect по мазкам кисти.
- Кинематический контроллер (капсула + прилипание к земле), движение кликом и WASD, превью пути через `Gizmos`.
- Команды: `MoveActor{id,to}`, `QueryPath{from,to}`.
- Приёмка: тесты пути вокруг препятствия и стоимости сложной местности, скриншот пути на склоне.

## Модуль 2. `arc_rules`: Pathfinder 2e
Чистая библиотека, seed-RNG. Проверки d20 с 4 степенями успеха, владение (уровень + ранг), AC/сейвы/HP/dying/wounded, состояния со значением, 3 действия + реакция, MAP, данные из RON/JSON. Лицензия: механики по ORC, без названий и мира Golarion.

## Модуль 3. `arc_actors`: NPC, фракции, триггеры
Reflect-компоненты `Actor`, `Stats`, `Faction`, `Perception`, `Inventory`, `Interactable`; шаблоны `assets/actors/*.ron`; триггер-объёмы (enter/exit/interact); undo/redo через `UndoHistory`; команды `SpawnActor`, `SpawnTrigger`, `SetFaction`, `ListActors`.

## Модуль 4. `arc_encounter`: бой
Режимы Exploration/Encounter, инициатива, непрерывное движение внутри хода, реакции по сегментам пути (Reactive Strike), линия видимости/укрытие по рейкасту, фланкинг по углу, области (burst/cone/line). Позже: режим real-time-with-pause.

## Модуль 5. `arc_dialogue`: диалоги и квесты
Граф узлов RON/JSON с условиями (флаги, проверка навыка против DC, предмет) и эффектами; ресурс `WorldFlags` в reflect-сцене; панель egui; команды `StartDialogue`, `SetFlag`.

## Риски
1. Совместимость сторонних крейтов с Bevy 0.20 проверять до подключения.
2. Растр проходимости на большом мире: интерфейс сразу чанковый.
3. ORCA и непрерывные реакции отлаживать детерминированными тестами на seed.
4. Модули 4 и 5 удерживать в жёстком минимуме первой версии.
