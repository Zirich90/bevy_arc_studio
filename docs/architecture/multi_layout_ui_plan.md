## Модель состояния

Одна оболочка выбирает Classic, Focus или Smart. Общие панели вызывают существующие команды и читают текущее состояние редактора. Отдельное UI-состояние хранит выбранную компоновку, Smart Workspace, размещение, размеры, доки и HUD. Для каждой компоновки свой набор настроек панелей. Начать с общего профиля Smart и дефолтов по Workspace. Добавлять индивидуальные настройки по Workspace только при практической необходимости.

Каждая панель имеет стабильный ID, независимые open и pinned. Закрытие сохраняет закрепление, закрепление закрытой панели сохраняет её закрытой. Контекст автоматически меняется у открытой незакреплённой панели по правилам режима. Закреплённая панель сохраняет показанный контекст при смене инструмента и Workspace. Inspector продолжает следовать выделению. Явно закрытая панель не должна сразу появляться снова из-за того же контекста. Отключённый модуль скрывает панель, предпочтения сохраняются по ID для повторного включения.

Смена представления не создаёт команду сцены или Undo. Сохраняются мир, выделение, инструмент, кисть, камера, история, материалы, префабы, графы и модули. В Play показывать допустимые игровые контролы и сохранить существующий приоритет игрового ввода. Смену layout во время активного drag применить на границе жеста, чтобы не потерять транзакцию.

## Последовательность реализации

1. **Инвентаризация и каркас.** Снять BRP baseline. Сделать матрицу «действие → существующий обработчик → вход в каждом режиме», включая панели модулей. Вынести выбор оболочки и общую модель панелей. Подключить один путь переключения, проверить отсутствие побочных эффектов по снимку состояния до/после.
2. **Classic.** File/Edit/View/Window/Help, переключатель, сохранение и общий блок запуска. Один верхний Toolbar. Слева SceneTree с поиском, rename и reparent, справа Inspector и расширения, снизу сворачиваемый и изменяемый по высоте Asset Browser. Перенести статистику в статус или компактный HUD, параметры качества и окружения оставить доступны через меню.
3. **Focus.** Компактный верх, вертикальные инструменты с подписями в подсказках, максимальная область сцены, временные или закрепляемые панели справа и снизу. Контекст Transform, кисть, вода или Build брать из реального инструмента и выделения. Док рисовать по open/pinned. Проверить ввод поверх дока, плавающих панелей и палитры до перехода к Smart.
4. **Smart.** Scene — иерархия, Inspector, спавнер, ассеты, префабы, материалы, Quillshade и графы. Terrain — генерация, кисти, слои и растительность с основными и расширенными параметрами. World — свет, атмосфера, туман, качество, глобальная вода и отдельные Water Bodies. Build — палитра, этажи, стены, комнаты, лестницы, крыши и привязка по текущим возможностям. Modules — штатное управление и Extensions/Other для неклассифицированных панелей. Workspace меняет доступные панели, явная команда меняет инструмент.
5. **Настройки и навигация.** Переиспользовать хранилище пользовательских предпочтений либо ввести отдельный версионированный конфиг UI. Дефолты, безопасная обработка повреждённых данных, ограничение размеров по окну, отложенная атомарная запись при изменениях и сброс текущей/всех компоновок. View → Interface Layout и Command Palette через существующие обработчики и EditorRegistry. Проверить конфликты перед Ctrl+K и Ctrl+Shift+1/2/3, сохранить F для Focus Selected. Стрелки, Enter и Esc в палитре. При тесном окне убирать второстепенные контролы в меню и сохранять доступ к панелям.
6. **Приёмка и передача.** Прогнать матрицу, обновить руководство пользователя и документацию регистрации панелей. Сохранить промпт и технический лог каждого этапа по AGENTS.md. Зафиксировать статус, результаты и следующий шаг в общей памяти после принятия.

## Проверки и критерии готовности

- Автоматически: roundtrip настроек, отсутствующий и повреждённый конфиг, ограничения размеров, reset, независимость профилей, все четыре комбинации open/pinned, смена контекста и отсутствие панели модуля. Проверить независимость Workspace, инструмента и сцены, расчёт UI-захвата указателя.
- Сценарии A–F дополнения: Classic → Focus → Smart → Classic с Move, выделением и камерой; Terrain при Move и явное включение кисти; закрепление → закрытие → повторное открытие; смена незакреплённого контекста; рестарт с разными профилями; подсветка дока по видимости.
- Сквозные проверки: добавить и править объект, rename/reparent, picking и gizmo, кисть, Build, Water Bodies, префабы, материалы, Quillshade, Node Graph, модули, сохранение и загрузка, Undo/Redo, BRP, PIE rollback и Separate Game. Проверить доступ из всех режимов через панели, меню или палитру. Отдельно проверить клик, drag, колесо и ввод в текстовых полях поверх сцены.
- При переключениях не перегенерируется мир, не перезагружаются ассеты и не меняется история. Скрытые панели пропускают работу, нужную только для отображения.
- Cargo максимально через Stop-хук: `python scripts/cargo_stop_hook.py check test`, сохранить ID и журнал. Короткий прямой Cargo допустим по AGENTS.md, если результат нужен внутри хода или хук недоступен. Не дублировать прогоны.
- BRP `brp_extras/screenshot` в `docs/screenshots/`: три режима на 1600×900, ручная проверка также на 1280×720 и 1920×1080. Просмотреть кадры, проверить контраст, переполнение, доступность контролов и размеры viewport. Oracle PASS только после реальных просмотренных кадров и функциональных проверок.
