Выполни **Этап 07: arc_movement — Навигация без сетки (Theta* + Funnel), тактический Click-to-Move и замер пути в футах (BG3 / WotR Style)**.

Сохрани текст этого промпта в `docs/clean_room_audit/prompts/stage_07_prompt.md`.
Прочитай `CLAUDE.md`, `docs/architecture/06_tactical_rpg_framework.md` и `src/arc_core.rs`.
Помни: компиляцию проверяй строго через `cargo check --message-format=short -q`.

### Задачи этапа:
1. **Чистое ядро навигации в `src/arc_core.rs` (или `src/navigation.rs`):**
   - **Растр проходимости (Traversability Grid, шаг 0.5м):**
     - Строится по `HeightfieldGrid` и `SceneObject`: непроходимыми считаются крутые склоны (уклон > 45°), глубокая вода (`height < water_level - 0.5`) и габариты пропсов (деревья, валуны, постройки).
     - Препятствия автоматически расширяются на радиус агента (0.35м), чтобы актор не цеплялся углами.
     - Сложная местность (вода по щиколотку, грязь/болото) помечается флагом `DifficultTerrain` со стоимостью движения ×2 (по правилам PF2e).
   - **Any-Angle Pathfinding (Theta* + Funnel Algorithm):**
     - Поиск пути без привязки к 8 направлениям сетки, дающий прямые естественные траектории между точками прямой видимости.
     - Интегральный расчет длины пути в метрах и конвертация в футы через `UnitScale` (с учетом штрафов за сложную местность).

2. **ECS-слой и Кинематический Контроллер (`src/movement.rs`):**
   - Компоненты `Mover { speed_feet: f32, radius: f32 }`, `WaypointsPath { points: Vec<Vec3>, current_idx: usize, total_feet: f32 }`.
   - Кинематическое перемещение: актор плавно движется по сплайну пути, а его высота `Y` каждый кадр привязывается к рельефу через `sample_height(x, z)`. Никакой нестабильной физики!
   - Локальное избегание (RVO/ORCA или простой радиус отталкивания): акторы не проходят сквозь друг друга.

3. **Интерактивный ввод и Визуализация Пути (BG3 Style):**
   - В режиме Play (`Tab`): при наведении мыши на террейн строится путь от выбранного актора до курсора.
   - Траектория пути рисуется через `Gizmos` (зеленая светящаяся линия, прилипающая к рельефу).
   - Рядом с курсором отображается аккуратная плашка: `Path: XX ft` (и желтый цвет, если путь проходит через сложную местность или превышает базовую скорость 25 ft).
   - Клик ЛКМ отправляет актора в путь.

4. **Команды для ИИ-агентов (`StudioCommand` в `src/mcp_commands.rs`):**
   - Добавь команды:
     - `QueryPath { from: Vec3, to: Vec3 }` -> возвращает `{ distance_meters, distance_feet, cost_feet, is_reachable }`;
     - `MoveActor { entity: Entity, to: Vec3 }` -> запускает движение.

### Проверка этапа (Oracle PASS / FAIL):
1. Напиши юнит-тесты на Theta* (обход препятствия по кратчайшей прямой и расчет ×2 стоимости для сложной местности). `cargo test --message-format=short -q` (все тесты зеленые).
2. Запусти студию, выбери актора (утку или тестового персонажа), отправь его кликом мыши (или командой `MoveActor`) вокруг озера или валуна.
3. Сними скриншот через BRP (`stage_07_path_preview.png`) с видимой линией траектории пути и замером в футах на склоне.
4. Проверь глазами, что путь гладкий, без зигзагов и не врезается в сосны. Запиши лог в `docs/clean_room_audit/logs/stage_07_log.md`.
