# Stage 10 / Layout 07 — закрытие матрицы Multi-Layout UI

Дата: 2026-11-11.

## Запрос владельца

«Продолжи работу. По журнал Multi-Layout UI и матрицу приёмки. Нужен вид как на
скриншотах 1600×900 в папке docs/screenshots/ArcStudio_3_Layouts: Classic, Focus и
Smart Scene.»

## Контекст

Реализация Classic/Focus/Smart готова (src/ui/layout.rs, общий реестр панелей,
меню, палитра, Ctrl+Shift+1/2/3). Журнал stage_10_layout_review_log.md и матрица
multi_layout_matrix.md фиксируют частичную приёмку. Референсные кадры сняты с
текущей сборки и просмотрены.

## Оставшиеся проверки (цель этапа)

1. Сверить текущий вид трёх раскладок с референсами 1600×900 (BRP-кадры, просмотр).
2. Живая правка компонента через Inspector: новое значение через BRP, точный Undo.
3. Захват клика/drag/колеса/клавиатуры над палитрой, Scene Tree и Assets.
4. Отсутствие повторной загрузки ассетов при смене раскладки по событиям AssetServer.
5. Восстановление закреплённой панели отключаемого модуля (тест + живой Modules On/Off).
6. Итоговые журналы, обновление матрицы и общей памяти. Oracle PASS только после
   полной приёмки.

## Ограничения

- Cargo через Stop-хук либо короткая команда с --message-format=short -q.
- Вся математика в arc_core.rs; сгенерированные файлы Quillshade не править.
- Скриншоты через brp_extras/screenshot в docs/screenshots/, обязательный просмотр.
- Коммит/push только по явному запросу владельца.
