# Этап E0: базовая линия редактора

Запрос владельца: «Начинай с этапа E0 с настройками по умолчанию».
Задача (из `docs/architecture/07_editor_plan.md`, раздел 4): зафиксировать тесты, снимок редактора, список команд; CI-матрица Win/Linux/macOS (сборка и тесты).

Решения по умолчанию для открытых вопросов (раздел 5):
1. Цель: редактор под конкретную игру с пилотом (E7).
2. Формат сцены: остаётся `DynamicWorld` (`.scn.json`), за интерфейсом.
3. `dynamic_linking` в `Cargo.toml` не трогаем (версии и фичи зафиксированы правилами проекта).
4. Проба Jackdaw не делается.
