# Этап E1: единая история отката и командный канал

Запрос владельца: «Сразу после закрытия E0 переходи к выполнению Этапа E1 (Единая история отката и командный канал) по нашему плану `docs/architecture/07_editor_plan.md`».
Задача (раздел 4 плана): свести истории правок к одному хронологическому порядку; `Reparent` откатывается.
Приёмка: тест «смешанная цепочка правок откатывается в обратном порядке»; тот же сценарий через BRP; снимок.
Запуск для снимков на Windows: `WGPU_BACKEND=dx12`, без `-WindowStyle Minimized`.
