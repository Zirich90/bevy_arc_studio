# Этап: план ECS-редактора

Запрос владельца: нужен полноценный 3D-редактор для Bevy, мощный, со спецификой Bevy и Rust.
Задачи: кроссплатформенность; основа на ECS, а не копия подхода Unity или Fyrox; автономность.
Редактор как цепочка плагинов (террейн, звук, стены и т.д.).
Сначала изучить, что есть у Bevy и других (Jackdaw, Fyrox и др.), затем составить план.
Результат: `docs/architecture/07_editor_plan.md`.
